# Leeshani Dilthara — Portfolio

Personal portfolio website for **Leeshani Dilthara**, Computer Science graduate (Second Upper), showcasing selected software, computer-vision, and IoT projects.

## Website

The site is a responsive static website built with HTML, CSS, and vanilla JavaScript. It includes:

- Professional introduction and contact links
- Technical skills overview
- Featured project summaries with direct repository links
- Education and achievement highlights
- Responsive navigation and reduced-motion support

## Featured repositories

- [AquaVision](https://github.com/LeeshaniZ/AquaVision) — YOLOv8-based fish detection prototype with Flask and ESP32 sensor integration.
- [AgriConnect](https://github.com/LeeshaniZ/Agriconnect-Website) — agricultural inventory, supplier, and purchase-order management application.
- [Smart Buoy Dashboard](https://github.com/LeeshaniZ/RealTime-Buoy-IoT-Dashboard) — IoT water and weather monitoring dashboard.
- [LabRay](https://github.com/LeeshaniZ/Labray-Laboratories-Management-System) — laboratory management desktop application.

## Run locally

No build tools are required. Open index.html in a browser, or serve the repository with any static web server.

## Deployment

This repository is structured for GitHub Pages deployment from the root of the main branch. Enable Pages in the repository settings to publish the site.
